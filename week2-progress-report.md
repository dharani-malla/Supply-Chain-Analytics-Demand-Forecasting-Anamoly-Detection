# Week 2 Progress Report

## Project Title
Supply Chain Analytics: Time-Series Analysis, Demand Forecasting, and Inventory Optimization

## Introduction
The objective of this project is to analyze retail inventory and sales data using time-series analytics to identify demand patterns, detect anomalies, 
perform demand forecasting, and generate insights for inventory optimization. During Week 2, the primary focus was on implementing anomaly detection 
techniques to identify unusual demand patterns and compare multiple anomaly detection methods.

## Week 2 Progress Summary
During Week 2, the team focused on statistical anomaly detection using both the Interquartile Range (IQR) method and the Isolation Forest algorithm. 
The work involved identifying anomalies, comparing the performance of both techniques, creating visualizations, exporting analysis results, and
documenting the complete anomaly detection workflow.

## Work Completed

### 1. Statistical Anomaly Detection using IQR
- Implemented the Interquartile Range (IQR) method for anomaly detection.
- Calculated Q1, Q3, and IQR values.
- Identified lower and upper threshold limits.
- Detected and labeled anomalous records based on IQR thresholds.

### 2. Machine Learning-Based Anomaly Detection
- Implemented the Isolation Forest algorithm for anomaly detection.
- Trained the model using the prepared dataset.
- Predicted anomalous observations using the trained model.
- Added anomaly labels to the dataset for further analysis.

### 3. Comparison of Anomaly Detection Methods
- Compared anomaly detection results generated by IQR and Isolation Forest.
- Identified common anomalies detected by both methods.
- Identified anomalies unique to each technique.
- Calculated the agreement percentage between the two methods.

### 4. Visualization and Analysis
- Created a bar chart comparing anomaly counts detected by both methods.
- Generated a box plot highlighting IQR-based outliers.
- Visualized Isolation Forest anomalies using a scatter plot.
- Created a pie chart showing agreement and disagreement between the two methods.
- Documented observations for each visualization.

### 5. Exporting Results
- Exported the anomaly comparison results to a CSV file.
- Exported the final merged dataset containing anomaly labels.
- Organized outputs for future demand forecasting and inventory optimization.

### 6. Documentation
- Documented the anomaly detection methodology.
- Documented algorithm comparison, visualizations, and observations.
- Updated the project README with Week 2 implementation details and progress summary.

## Key Insights and Learnings
- Statistical and machine learning methods identify anomalies using different approaches.
- IQR effectively detects extreme statistical outliers.
- Isolation Forest can identify complex anomaly patterns in the dataset.
- Comparing multiple methods improves confidence in anomaly detection results.
- Visualizations provide better understanding of anomaly distribution and model agreement.

- Comparing results generated by different anomaly detection techniques.
- Organizing visualizations and documentation in a structured format.
